# Support

Need help with ShetBhav? Here's where to go.

## Bugs and feature requests

Open an issue on GitHub:

- **Bug reports** — include the page/route, what you did, what you expected, and what happened. Screenshots help.
- **Feature requests** — describe the problem you're trying to solve, not just the feature.

Use the issue templates described in [CONTRIBUTING.md](shetbhav/CONTRIBUTING.md) if available.

## Setup and deployment questions

Before asking, check these — they cover most questions:

- [README.md](README.md) — setup, demo accounts, how to run backend/frontend
- [shetbhav/DEMO.md](shetbhav/DEMO.md) — the seeded demo flow, step by step
- [shetbhav/LIMITATIONS.md](shetbhav/LIMITATIONS.md) — what is and isn't supported
- [shetbhav/DATA_SOURCES.md](shetbhav/DATA_SOURCES.md) — market data, live/cached/demo behavior

## Security issues

Do **not** open a public issue for security problems (leaked credentials, auth
weaknesses, etc.). See [shetbhav/SECURITY.md](shetbhav/SECURITY.md) for how to
report them privately.

## Scope of support

ShetBhav is an MVP built for Smart India Hackathon 2026 (problem SIH26132).
It is demo- and evaluation-focused; the team provides best-effort support on a
volunteer basis and cannot guarantee response times.
